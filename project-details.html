Project Description

We are looking for a skilled Full Stack Web Developer to build a modern and responsive E-Commerce website. The website should allow customers to browse products, add items to the cart, make secure online payments, and manage orders. An admin panel should also be included for managing products, users, and orders.

The application must provide an attractive user interface, excellent performance, responsive design, and secure authentication. Clean, well-documented code is expected.


Responsibilities

  • Develop responsive web pages.
  • Create product listing and product details pages.
  • Implement shopping cart functionality.
  • Integrate secure payment gateway.
  • Build user login and registration system.
  • Create admin dashboard.
  • Optimize website performance.
  • Fix bugs and perform testing.

Requirements

  • Minimum 3 years of web development experience.
  • Strong knowledge of HTML, CSS and JavaScript.
  • Experience with PHP and MySQL.
  • Knowledge of Bootstrap framework.
  • Experience integrating payment gateways.
  • Good communication skills.
